# Förderradar DACH + EU

Kostenloser abonnierbarer Apple-Kalender. In `calls.csv` nur geprüfte Calls mit `status=verified` eintragen (Datum `YYYY-MM-DD`). GitHub Actions erzeugt und veröffentlicht täglich die `.ics`-Datei.

**Wichtig:** Diese Version aktualisiert den Kalender aus `calls.csv`, recherchiert aber noch keine neuen Ausschreibungen selbstständig. Für echte automatische Call-Recherche ist eine zusätzliche verlässliche Datenquelle/Importlogik nötig. Fristen vor Einreichung beim Anbieter prüfen.

Nach Upload: Settings > Pages > Source **GitHub Actions** einstellen. Dann Actions > Kalender aktualisieren > Run workflow.

Kalender-URL: `https://52dcg52f27-ui.github.io/Foerderradar/foerderradar.ics`
